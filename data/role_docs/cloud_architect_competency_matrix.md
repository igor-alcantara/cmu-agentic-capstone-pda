# Cloud Architect: Competency Matrix

## How to read the matrix
Skill levels run from one to five. Level one is awareness: the person knows what the tool is for. Level two is supervised use on delivery work. Level three is independent delivery on a typical engagement. Level four is the level expected of someone who leads that part of an engagement and reviews others. Level five is recognized expertise across the practice, the person others escalate to. Role requirements below name the level at which a practitioner is considered fully effective; a gap is any skill below that level.

## Required levels by skill
AWS: required level 4. AWS is the default cloud for most engagements.
Azure: required level 3. Azure appears with clients on the Microsoft stack.
Terraform: required level 4. Terraform is the infrastructure-as-code standard.
Networking: required level 4. Networking knowledge keeps architectures secure and debuggable.
Cloud Security: required level 4. Cloud security is non-negotiable for every design.
Kubernetes: required level 3. Kubernetes appears where clients run their own services.
Cloud Cost Optimization: required level 3. Cloud cost optimization is a recurring client concern.
Snowflake: required level 2. Snowflake is the primary warehouse for most client work.

## Skills adjacent to the role
Adjacent skills are welcome and sometimes decisive on a specific client, but they do not count toward the role requirements and a plan should not prioritize them over a gap. SQL remains the working language of every engagement. Python is the glue for ingestion, transformation, and testing. dbt is the transformation standard. Data modeling underpins everything downstream. Apache Airflow orchestrates scheduled pipelines. Apache Spark handles workloads that do not fit a single warehouse query. Talend is still in production at several long-standing clients. Kafka appears where a client needs streaming ingestion. Git is the collaboration baseline. Qlik Sense is the core analytics platform for the consulting practice. Qlik scripting builds the data layer inside the app.
