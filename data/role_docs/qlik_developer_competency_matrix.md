# Qlik Developer: Competency Matrix

## How to read the matrix
Skill levels run from one to five. Level one is awareness: the person knows what the tool is for. Level two is supervised use on delivery work. Level three is independent delivery on a typical engagement. Level four is the level expected of someone who leads that part of an engagement and reviews others. Level five is recognized expertise across the practice, the person others escalate to. Role requirements below name the level at which a practitioner is considered fully effective; a gap is any skill below that level.

## Required levels by skill
Qlik Sense: required level 4. Qlik Sense is the core analytics platform for the consulting practice.
Qlik Scripting: required level 4. Qlik scripting builds the data layer inside the app.
Set Analysis: required level 4. Set analysis is how advanced expressions are written in Qlik.
Data Modeling: required level 4. Data modeling underpins everything downstream.
Qlik Cloud Administration: required level 3. Qlik Cloud administration covers tenant configuration, spaces, reload scheduling, identity provider integration, and license management.
SQL: required level 3. SQL remains the working language of every engagement.

## Skills adjacent to the role
Adjacent skills are welcome and sometimes decisive on a specific client, but they do not count toward the role requirements and a plan should not prioritize them over a gap. Python is the glue for ingestion, transformation, and testing. Snowflake is the primary warehouse for most client work. dbt is the transformation standard. Apache Airflow orchestrates scheduled pipelines. Apache Spark handles workloads that do not fit a single warehouse query. Talend is still in production at several long-standing clients. Kafka appears where a client needs streaming ingestion. Git is the collaboration baseline. Data visualization is the consultant's craft.
