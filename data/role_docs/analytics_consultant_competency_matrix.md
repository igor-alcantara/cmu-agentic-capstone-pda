# Analytics Consultant: Competency Matrix

## How to read the matrix
Skill levels run from one to five. Level one is awareness: the person knows what the tool is for. Level two is supervised use on delivery work. Level three is independent delivery on a typical engagement. Level four is the level expected of someone who leads that part of an engagement and reviews others. Level five is recognized expertise across the practice, the person others escalate to. Role requirements below name the level at which a practitioner is considered fully effective; a gap is any skill below that level.

## Required levels by skill
SQL: required level 3. SQL remains the working language of every engagement.
Qlik Sense: required level 4. Qlik Sense is the core analytics platform for the consulting practice.
Data Visualization: required level 4. Data visualization is the consultant's craft.
Requirements Gathering: required level 4. Requirements gathering turns a vague ask into a scoped deliverable.
Stakeholder Communication: required level 4. Stakeholder communication is the difference between a delivered dashboard and an adopted one.
Statistics: required level 3. Statistics at the expected level means confidence in descriptive statistics, an honest grasp of variance and sampling, and knowing when a difference on a chart is noise..
Data Storytelling: required level 3. Data storytelling is how findings survive the meeting.
Python: required level 2. Python is the glue for ingestion, transformation, and testing.
Data Modeling: required level 3. Data modeling underpins everything downstream.

## Skills adjacent to the role
Adjacent skills are welcome and sometimes decisive on a specific client, but they do not count toward the role requirements and a plan should not prioritize them over a gap. Snowflake is the primary warehouse for most client work. dbt is the transformation standard. Apache Airflow orchestrates scheduled pipelines. Apache Spark handles workloads that do not fit a single warehouse query. Talend is still in production at several long-standing clients. Kafka appears where a client needs streaming ingestion. Git is the collaboration baseline. Qlik scripting builds the data layer inside the app. Set analysis is how advanced expressions are written in Qlik.
